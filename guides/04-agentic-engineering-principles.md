## 📌 The 8 Agentic Engineering Rules

Derived from over 60 billion token evaluations across autonomous AI software agents, these principles govern efficient software construction:

1. **Investigate Before Designing**: Always inspect codebase conventions and existing utility classes before writing custom helpers from scratch.
2. **Adopt Proven Patterns**: Follow established architectural patterns and project file layout conventions.
3. **Prioritize Simplification**: Delete unused code paths and redundant helper layers rather than maintaining backward-compatibility bloat.
4. **Seek the Simplest Implementation**: Choose direct, working solutions without speculative abstractions.
5. **Build in Layers**: Deliver a working end-to-end Minimum Viable Product (MVP) first, then iterate incrementally.
6. **Maintain Modular Structure**: Enforce clear separation of concerns across components and data schemas.
7. **Leverage Existing Dependencies**: Inspect existing library capabilities and standard library utilities before adding new external packages.
8. **Think Long-Term**: Make clean, maintainable architectural decisions over temporary quick-fix hacks.
